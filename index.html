How the Double Attack is timed

The first hit uses the selected skin's configured windup. A Double Attack then resets the attack timer to 75% of that windup. The timer climbs from that reset to the 1.5s AttackDuration, followed by one idle tick.

Speed multiplier s = 1 + AS / 100
FD6 increment inc = floor(dtRaw × round(s × 1e6) / 2³²)
First-hit ticks ceil(windup / inc)
Recovery ticks ceil((1.5 − 0.75 × windup) / inc)
Double cycle firstHit + recovery + 1 idle tick
Effective time / hit (normal + DC × gap) / (1 + DC)

The website uses the game's fixed-point increment for breakpoint calculations rather than the simplified 0.1 × speed approximation. AS values are displayed to three decimals.
